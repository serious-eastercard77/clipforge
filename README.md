## 🧠 Usage

After running clipforge, everything you copy (text, links, code snippets) is automatically stored in a secure, searchable history. Here’s how to use it:

### Core Actions
- **Open the history:** Press `Ctrl + Shift + V` anywhere.
- **Search your clipboards:** In the pop-up window, just type part of what you remember (e.g., “invoice”).
- **Paste a saved item:** Click any clip, and it’s instantly pasted into your currently active app.
- **Pin important clips:** Hover over a clip and click the 📌 icon to keep it at the top forever.
- **Delete a clip:** Right-click a clip and choose *Delete*.
- **Clear all:** Right-click the tray icon and select *Clear History*.

### Pro Tips
- clipforge auto-detects copied images and files too—no extra setup.
- Use your mouse only or keyboard shortcuts—both fully supported.
- Toggle “Auto-paste after select” in settings (gear icon) for even faster experience.

## 🔧 Troubleshooting

| Problem | Solution |
|---|---|
| Nothing opens when I press Ctrl+Shift+V | Make sure you’re in a text field (like a browser bar, Notepad). If still not, restart clipforge from the tray icon. |
| The download doesn’t start | Try right-clicking the download button and selecting “Save link as…” — then save to Desktop. |
| Windows warns about unknown publisher | Click **More info** → **Run anyway**. clipforge is digitally signed but may not be universally recognized yet. |
| The pop-up disappears instantly | Ensure you’ve copied something first. Copy any text, then try the shortcut again. |
| App freezes or crashes | Send us a crash report—see Support below. Also close and restart from the tray. |
| I don’t see the tray icon | Click the **up arrow** (system tray overflow) to find it. Right-click it and choose “Pin to tray”. |
